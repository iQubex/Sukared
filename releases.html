Luavex 2.2 — Runtime Integrity & Authorization

Current

Improved

  • Strengthened server-authorized runtime execution.
  • Improved invocation and context isolation.
  • Expanded runtime integrity validation and per-build execution diversity.
  • Reduced recovered material lifetime through bounded lazy recovery.
  • Added capability-aware compatibility profiles.
  • Improved replay and malformed-context resistance.
  • Runtime consistency, size and performance maintenance.
